Лабораторная 11. Параметрические кривые

Запуск:
python lab11.py

Что сделано:
1. Задача А - кривая Безье по 4 точкам. На экране есть характеристическая ломаная
   и промежуточные построения для нескольких значений параметра.
2. Задача Б - можно переключаться между Безье, B-Spline и Катмулл-Ром.
   Точки можно добавлять двойным кликом, двигать мышкой и удалять правой кнопкой.
3. Задача В - режим NURBS. Для выбранной точки можно менять вес ползунком,
   после этого видно, как вес влияет на форму кривой.

Управление:
- ЛКМ по точке - выбрать точку.
- Перетаскивание ЛКМ - переместить точку.
- Двойной ЛКМ на поле - добавить точку.
- ПКМ по точке - удалить точку.
- Ползунок веса работает в режиме NURBS.
