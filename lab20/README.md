# Лабораторная работа 20. Анимация скелета

Запуск:

```bash
python lab20.py
```

Что сделано:

1. Задача A: создан 2D-скелет из 4 костей в иерархии `shoulder -> upper arm -> forearm -> hand`. В режиме `Forward kinematics` углы костей меняются ползунками, а поворот родительской кости влияет на все дочерние.
2. Задача Б: реализована интерполяция между двумя позами. В режиме `Pose interpolation` программа циклически смешивает Pose A и Pose B, получается простая анимация руки.
3. Задача В: реализована обратная кинематика методом CCD. В режиме `Inverse kinematics CCD` конечная точка `hand` стремится к цели, которую можно задавать мышью на canvas.

Дополнительно:

- На экране показаны суставы, кости и простая "кожа" вокруг костей.
- Бледные силуэты показывают две ключевые позы для интерполяции.
- Справа выводятся текущие углы костей и ошибка попадания конечной точки в цель.
